## Historical evidence

`VERIFICATION.md`, `IMPLEMENTATION_PLAN.md` and `PHASE_*_REPORT.md` describe earlier
stages. `CAMERA_CAPTURE_REPORT.md`, `LIVE_CAMERA_REPORT.md`, `LIVE_COLOUR_FIX.md`,
`EDGE_COVERAGE_FIX.md` and `DESIGN_UPDATE.md` record specific changes and their
measurements. Their old file paths, test counts and deployment state describe
those snapshots; they are not the current setup instructions.

Local PDFs under the repository's `deliverables/` folder are presentation
snapshots. Source navigation and architecture explanations should use these
current guides. The private source brief and local `.env` are not public assets.
